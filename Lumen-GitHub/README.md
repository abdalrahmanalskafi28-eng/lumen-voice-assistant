# لومين (Lumen) — مساعد صوتي بالعربي لويندوز

مساعد صوتي بلهجة عفوية. ناديه "لومين" وبيفتح مواقع وبرامج، وبيحط مؤقت، وبيسجل ملاحظات، وبيجاوب على أسئلتك بصوت أنثوي ناعم.

> مشروع شخصي تجريبي. مجاني ومفتوح المصدر (ترخيص MIT).

## شو بيعمل

- فتح مواقع وبرامج ومجلدات وتسكيرها ("افتح يوتيوب"، "سكري الحاسبة")
- بحث بجوجل ويوتيوب وتشغيل أغاني
- التحكم بالصوت والموسيقى
- مؤقت وملاحظات صوتية
- الوقت والتاريخ والطقس
- قفل الجهاز أو إطفاؤه
- أي سؤال ثاني بيجاوب عليه بالذكاء الاصطناعي (Groq)

## المتطلبات

- ويندوز
- مايك وإنترنت
- بايثون من [python.org](https://www.python.org/downloads/)، مع تفعيل **Add python to PATH** وقت التنصيب
- مفتاح Groq مجاني من [console.groq.com](https://console.groq.com)

## التنصيب

1. حمّل الملفات (Code ← Download ZIP) وفك الضغط.
2. دبل كلك على `install.bat`، وبيفتحلك Notepad باسم `groq_key.txt`. الصق مفتاح Groq الخاص فيك (المفتاح بس)، احفظ وسكّر.
3. دبل كلك على `test_jarvis.bat` وناديها: **"لومين"**.

للتشغيل التلقائي بدون شاشة: كلك يمين على `start_jarvis.vbs` ← Create shortcut، وحط الـ shortcut بمجلد التشغيل التلقائي (`Win + R` ثم `shell:startup`).

أو بالأمر مباشرة: `pip install SpeechRecognition gTTS playsound==1.2.2 groq edge-tts pyaudio` ثم `python jarvis.py`.

## أمثلة أوامر

- لومين، كم الساعة
- لومين، سكري يوتيوب
- لومين، مع السلامة (بتنام وبتضل شغالة)
- لومين، اقفل البرنامج (بتسكّر كلياً)

## تنبيهات مهمة

- **الخصوصية:** البرنامج بيسمع دايماً، والكلام بيروح لخدمة التعرف على الصوت من Google لتحويلو لنص، والأسئلة بتروح لـ Groq.
- **مفتاحك الخاص:** لا تشارك ملف `groq_key.txt` مع حدا.
- **خدمات غير رسمية:** التعرف على الصوت وصوت الرد بيعتمدوا على خدمات مجانية غير مخصصة للاستخدام التجاري، وممكن تتغير أو تتوقف بأي وقت. المشروع للاستخدام الشخصي والتجريب.
- **بدون ضمان:** البرنامج مقدّم كما هو.
